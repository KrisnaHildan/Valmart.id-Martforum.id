## 🎭 Prinsip Kurasi Meme (Anti-Sok Asik / Anti-Cringe)
Sesuai arahan, konten meme tidak menggunakan istilah *slang* basi yang dipaksakan. Seluruh meme berakar langsung dari pengalaman dan dinamika nyata komunitas Valorant Indonesia:
1. **Blunder In-Game**: Aim recoil tembus langit pas nenteng Kuronami, panik pencet reload pas musuh defuse spike, spectate temen whiff tapi senjatanya glowing.
2. **Kultur Tongkrongan**: Budaya *"drop skin dong bang"* pas buy phase, perdebatan sekte skin (Kuronami vs Reaver vs Primordium), temen Discord yang pura-pura disconnect pas diajak top up.
3. **Momen Kritis**: Buka Daily Store jam 7 pagi dikutuk Smite & Convex, top up detik-detik kritis pas agent select sisa 30 detik.
4. **Realita Tanggal Tua**: Dompet tinggal recehan 20 ribu lecek tapi pas mabar malam minggu tetap bisa sombong nenteng skin sultan hasil sewa Valmart.
